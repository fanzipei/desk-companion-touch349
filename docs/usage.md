# 使用与触屏交互

本仓库只适配 Waveshare ESP32-S3-Touch-LCD-3.49 **V2 / Rev1.1**，横屏 640 × 172。安装 PC 后台与固件后，在设置中指定实际 BLE 地址；型号不符合时后台拒绝同步。

## 发送到小屏

- 选中文字，按 `Ctrl+Alt+J` 静默加入便签；剪贴板内容尽量恢复。
- 按 `Ctrl+Alt+空格` 输入便签，回车发送；输入法仍在选词时不会误发送。
- 启用并配置图片模型后，`Ctrl+Alt+K` 框选截图。只有框选区域进入识别请求。
- 便签最长 3072 UTF-8 字节，默认最多 20 条；未连接时持久排队，全部置顶或待发送已满时保留待发送内容。

## 小屏

| 操作 | 结果 |
| --- | --- |
| 空闲 10 秒 | 自动全屏 |
| 操作界面双击正文 | 立即全屏，前 2 秒轻点不会误退出 |
| 全屏轻点 | 保护期后退出全屏 |
| 上下拖动 | 同一条内容连续浏览 |
| 左右滑动 | 切换前后便签或新闻，新闻优先未读 |
| 全屏按住约 0.6 秒后左滑 | 松开弹删除确认，确认后才删除 |
| 全屏按住后右滑 | 便签在 PC 消息窗打开，新闻在浏览器打开 |
| 操作界面按钮 | 模式切换、置顶、删除、字号、主题 |
| 横屏左右两端对调 180° 并停稳 | 切换便签/新闻，同时文字和触摸转正 |

自动播放只向下滚动：开始和每次回到开头等待约 5 秒，滚到末尾等待 12 秒，再跳回开头。退出全屏时正文整体缩小，保留换行关系和阅读位置。

PWR 负责息屏和唤醒；RESET 复位；BOOT 不发送、删除或切换内容。没有 Ctrl+Alt+L 定时提醒，旧提醒数据不会执行。

## 新闻和模型

在“设置 → 新闻推荐”启用个性化 RSS。通常将“翻译、正文简讯”设为本地 Ollama 或本地 OpenAI 兼容服务，“推荐、偏好学习”设为商业 API。每项都可独立更改；截图模型单独配置。参见[新闻推荐](news-personalization.md)。

队列默认 30 条，在 PC 可设为 1–50；置顶占用容量并受保护。满额先移除最早的已读未置顶新闻，再移除最早未读新闻。微信成功发出的新闻与小屏已读状态合并。全部未读浏览完后提示并进入重播；新消息提示一直保留到手动关闭，后续到达条数继续累加。

PC 关闭或断网不会清空设备缓存。开启后台后续传待发送便签，合并屏幕离线的置顶、删除、阅读与偏好反馈。

## 字体

12/16/24/32 字号均使用相同字形度量计算换行并绘制。WQY 未覆盖的字符使用 Flash 中的 Noto Unicode 后备字形；人名“·”、常见缺字和更多繁体正常显示，特殊空格保留为空白。极少数字库外的字符显示方框，原文的问号不被改动。

## 数据

运行时数据位于当前克隆的 `data/`，不随源码分发。模型密钥和微信会话由同一 Windows 用户的 DPAPI 加密；不能把密钥文件复制给其他 Windows 用户直接使用。更换目录时先备份 `data/`、确认设备型号，再使用缓存迁移工具；不要让一块空设备覆盖现有 PC 便签缓存。
