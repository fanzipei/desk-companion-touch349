# 微信便签与新闻

微信接入使用腾讯 ClawBot / iLink 专用会话，不读取普通好友聊天列表，也不依赖 PC 微信进程。账号是否具备连接能力以实际手机授权为准。

## 独立便签接入

在托盘“手机微信”，或“设置 → 快捷工具”选择独立扫码接入，用手机微信扫描并确认。随后向对应 ClawBot 会话发送文字，后台作为便签排队。API 密钥和微信登录互相独立，接入记录使用 Windows DPAPI 加密。

已有其他应用占用同一 ClawBot 连接时，不要启动第二个轮询器或反复扫码；应使用下面的共享方式。

## 可选：复用已有日历中继

本仓库包含**小伴侣侧消费者和新闻回复计划**；日历应用及其 iLink 轮询/发送器属于外部中继，不包含在此仓库，也不会因克隆本仓库而自动安装。

共享模式要求外部日历后台实现兼容的本机 SQLite 协议，并使用同一 Windows 用户：

- `wechat_meta` 中 `router/version=1` 及当前账号、本人 owner 标识。
- `wechat_jobs` 中，验证过的私聊文字按 `route='notes'` 或 `route='news'` 分流；便签载荷采用版本 1 加密信封，并去除回复令牌。
- 新闻计划写入 `wechat_news_parts(key,part,body,sent,applied)`；中继使用真实请求上下文发送每段，成功后才写 `sent=1`。
- 小伴侣持久保存对应已读 ID 后才置 `applied=1`。长简讯最后一段成功后才将该条标为已读；失败的条目仍未读。
- 中继处理便签/新闻时不得覆盖自己的日历草稿或路由追问；微信仍只有一个长轮询器。

实现细节见 `pc/wechat_shared.py` 和 `pc/wechat_news.py`，本机隔离验证见 `tests/test_wechat_shared.py`、`tests/test_wechat_news.py`。默认在同级 `桌面日历/data/calendar.sqlite3` 查找兼容中继，可通过 `WechatNotes.use_calendar(path)` 指定其他数据库路径。

兼容中继可将以下文字转给本应用：

| 文字 | 行为 |
| --- | --- |
| 帮我记下论文选题方向 | 去掉记录前缀，加入便签 |
| 便签：明天带电脑 | 显式作为便签，不推断提醒 |
| 最近推送的未读新闻发给我 | 取当前队列未读新闻 |
| 未读信息发送给我 / 未读消息发给我 | 新闻查询的同义表达 |
| 发我最近 5 条未读新闻 | 限制本次取阅数量 |
| 看看全部新闻 | 可包含已读新闻 |
| 只发未读新闻的标题 | 仅发送标题与链接 |

记录与日历的意图判断、缺少日期时追问、日历事件创建由外部中继负责。小伴侣已经移除定时提醒功能，不在本机重复创建提醒。

新闻查询使用已收集的中文标题、长简讯、来源及原文链接，不现场抓取文章或调用模型。发送成功后同步 PC/小屏已读；微信取阅不伪装成“PC 打开”的强兴趣反馈。并行请求避开正在发送的条目，重启后沿用原请求的发送计划。

若没有兼容中继，可以使用独立便签接入、普通小屏新闻与 PC 浏览器打开功能；共享模式的自然语言路由和微信新闻发送需要中继的对应能力。
